# Phenotype lexicon: the caption gate (#26).
#
# One term per line, lowercase, matched as a whole word on an image's *caption*.
# This list is tuned for PRECISION, unlike `agronomy_lexicon.txt`, which gates document
# text before a fetch and is tuned for recall.
#
# The distinction that matters: a term belongs here only if a caption containing it is
# likely to sit under a picture of a plant, an organ, a symptom or a growing scene.
#
# Crop names are NOT here; they live in `crop_lexicon.txt`, which nothing gates on. A
# crop name says what a document is about, not what a picture shows, and on its own it
# matched only proper nouns. See that file for the evidence.
# Terms that merely establish an agricultural *context* — field, plot, trial, soil,
# yield, farm, irrigation, variety, species, plant — are deliberately absent: they fire
# on economics, soil chemistry and ecology papers whose figures are charts and maps.
